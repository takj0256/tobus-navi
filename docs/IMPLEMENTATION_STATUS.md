## 回帰対象

```text
石島 → 扇橋一丁目：4分
扇橋一丁目 → 猿江一丁目：3分
```

石島イベントから猿江一丁目までを約7分として計算し、先行車が遅い場合は後続区間も延長することを自動テストで確認しています。

## 未展開・制限

- 公開フィードは連続GPSを提供しないため、停留所間位置は推定値
- R2・D1を設定してWorkerを公開するまでは端末ごとのPhase 10履歴だけを使用
- アプリを開いていない時間帯の実績は収集されない
- `current_status`、`TripUpdate`、`congestion_level` は現在の都営バス公開フィードに含まれない
- 運休・迂回・大幅な通信遅延では推定誤差が拡大する

- 週間プロファイルの本番採用は1～2週間のStage 1収集とMAEシャドー評価後に判断する
- 外部交通照会地点は現在、公開停留所座標間の中点。shape座標データをWorkerへ配備した場合はshape中央を優先する
- TomTomの契約条件と無料枠は公開直前に再確認する
