# Phase 11 小型MLPデモ

2026-09-18、サブPCで実学習とブラウザ再生を確認。本番未接続。

## 目的と重要な制約

「過去の基準値＋小型NNの残差補正」の学習・評価・JSON配布・ブラウザ推論を通す研究デモ。
目的変数はdaily-v2に保存された停留所切替前後の**観測間隔**であり、正確な区間走行時間や実到着ではない。
`collectSegmentEvents`は同一停留所であっても毎回previousを更新するため、secondsは最後の同停留所観測から次停留所観測までの差になる。
その前の走行・停車時間を含む保証はない。今回、収集器や本番統計の意味は変更していない。

当初案の本番残差学習には、予測入力・予測値・受信時刻・実到着定義・実績との対応付けが別途必要。
この実験の誤差低下を、本番到着予測の改善や信頼度として扱わない。

## 実装

- `tools/train_phase11_demo.py`：NumPyだけでMLP 11→32→16→1、ReLU、Huber損失、Adam、929パラメータ。GPU/クラウド学習なし。
- 先頭4日で頻出64区間を選択。それ以降の予測起点の日付を60%/20%/20%の学習・検証・テストへ分割。seed=11。最大60epoch、検証MAEによるモデル選択・12epoch改善なしで停止。
- 基準は区間別、当日0時より前の過去28日中央値（最低3観測）。本番の曜日/15分枠・7/28日混合とは異なる比較用基準。
- 特徴は基準値、MAD、履歴件数、時刻/曜日の周期表現、週末フラグ、直近の既知観測との差と鮮度・欠損フラグ。
- 予測起点は`timestamp_ms - seconds*1000`で再構成。履歴は完了観測時刻が予測起点より厳密に前のものだけ。直近値は120分超で欠損。受信時刻がないので配信遅延は再現しない。
- 天候・温度は終了時点の情報しかないため入力に使わない。連続GPS由来の速度、前走車の同定、時刻表、交通補正、季節補正は未実装。
- 学習データのみで正規化し±8にクリップ。NN補正は±120秒、出力は15～1800秒。検証・テストで重みは更新せず、観測済み履歴の特徴だけ逐次更新。
- 分割境界をまたぐ正解ラベルを学習/検証から除外。event_id重複除去、矛盾重複・重複グループは拒否。日付不一致・不正値を除外し件数を報告。
- 出力は`candidate_only`付きmodel/report JSONとテスト例100件、静的HTML/JS。JSが同じ重みで毎回推論し、Python値との一致を確認する。
- ソースJSONは読み取り専用。出力先は空の新規ディレクトリに限定し、以前の実験を上書きしない。D1/R2・Worker・PWA・バッチに接続しない。

## 初回実測（2026-09-18確認）

入力はローカル保存済みdaily-v2の2026-08-12～09-08、28日分。最新版の再取得は行っていない。
先頭4日を準備期間とし、学習8/16～8/29が53,116件、検証8/30～9/3が28,350件、テスト9/4～9/8が17,050件。
選択モデルはepoch 5。17epochで停止。

| テスト指標 | デモ基準値 | MLP補正後 |
| --- | ---: | ---: |
| MAE | 27.0763秒 | 25.2414秒 |
| P90絶対誤差 | 57.0000秒 | 53.5871秒 |
| ±15秒以内率 | 41.17% | 41.32% |
| ±30秒以内率 | 67.71% | 69.73% |
| ±60秒以内率 | 91.37% | 92.65% |

MAEは約6.78%低下。ただし頻出区間・単一期間・単一seedの代理目的評価で、統計的有意性・全路線・季節・本番改善は未確認。
テストを見て設定を再調整していない。次のモデル比較ではこのテストが既知であることを扱い、新しい期間も確保する。

## 再現・起動

動作確認環境：Python 3.10、NumPy 1.21.5、Node 22。NumPyが必要（通常のPWA依存へは追加しない）。
コマンドの`INPUT_DAILY_DIR`には手元のdaily-v2ディレクトリを指定する。

```bash
OPENBLAS_NUM_THREADS=1 python3 tools/train_phase11_demo.py INPUT_DAILY_DIR docs/local/ml-demo-new --segments 64 --epochs 60
node tools/check_phase11_demo.mjs docs/local/ml-demo-new
python3 -m http.server 8766 --bind 127.0.0.1 --directory docs/local/ml-demo-new
```

`http://localhost:8766/`で表示。ローカル限定サーバーであり外部公開ではない。サーバー停止時は再起動が必要。
ブラウザは同じディレクトリのmodel/report/examples JSONだけを読む。生イベントID・車両IDはデモ出力に含めない。
元データの内容ハッシュ、使用日、モデル重み、正規化、seed、学習曲線は出力に保存される。
成果物と元データは`docs/local/`等のGit管理外に保持し、Gitにはソース・テスト・要約結果を共有する。
他PCはソースのfetchに加え、別途データの準備または成果物コピーが必要。Git同期だけでデモが実行済みとは扱わない。

```bash
OPENBLAS_NUM_THREADS=1 python3 -m unittest discover -s tests -p test_phase11_demo.py
npm run check:js
npm run test:js
```

初回：Python 5件、JS 112件成功。テスト例100件でPython/JS推論差の最大は約2.84e-14秒。
ブラウザで指標・注意表示・「次の観測」の切替を確認。モバイル実機は未確認。
