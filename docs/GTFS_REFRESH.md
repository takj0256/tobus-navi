# 公式GTFS更新・停留所監査

## 構成

Phase11の04:15 JST実行が終了した後（集計成功・失敗は別判定）、同じサブPCから公式GTFS ZIPを取得する。成功日ガードのスキップ時も未完了のGTFS更新を試行できる。独立したロックと専用の公開用Gitコピーを使い、開発ツリー・集計入力・D1・R2統計を変更しない。GitHub Pagesの既存main公開を利用し、新規のCloudflare書き込みは発生しない。

`tools/refresh_gtfs.py` は標準ライブラリだけで取得・変換し、停留所座標、全系統/全便の停留所参照・時刻順、今日から8日間の運行便を検証する。停留所/系統が10%以上減る場合は自動公開を止め、手動確認へ回す。公式データを補間したり移設位置を推測したりしない。

系統JSONは内容SHA-256による固定URL（16桁）で公開し、直近8世代（現行＋過去7世代）のURLを保持する。初期の既存ファイルは削除せず、更新ツールの保持台帳に記録した自動生成ファイルだけを期限後に削除する。Gitから復元可能で、未知のファイルには触れない。全検証後に索引を最後に切り替える。公開サイトはPagesの世代単位で切り替わり、保持期間内の古い画面も旧系統を参照できる。古い画面は新版通知から再読込する。時刻のみの差では系統全件を書き直さない。日々の確認結果だけは `data/gtfs-status.json` に記録する。系統領域が450MiBを超える場合は自動公開せず容量調査へ回す。

毎回の変更比較に加え、月曜は端末上の前回週次基準から全乗り場を比較する。追加・削除・名称変更・5m以上の座標変更を記録し、過去統計のstop_idを自動で別IDへ付け替えない。初回は前回公開データを基準に全件監査する。工事による臨時移設がGTFSへ未反映の場合は検出不能であり、公式案内の確認が必要。

## 端末設定（Git管理外）

バッチルート内 `gtfs-refresh/` に、main専用のクリーンな `publish/` Gitコピー、固定起動用 `run_gtfs_refresh.sh`、有効化ファイル `enabled` を配置する。実際の絶対パス/リモートは端末管理とし、秘密情報は設定に追加しない。`refresh.log`、`status.json`、`success-date`、`audit-baseline.json` は端末内で保持する。既存Windows集計タスクの起動引数（TCP DNS設定含む）は変えず、集計コピーのスケジュールラッパーだけを退避後に差し替える。

```bash
bash tools/run_gtfs_refresh.sh /absolute/private/gtfs-refresh
# 検証・生成だけ（専用コピーや一時ディレクトリで行う）
python3 tools/refresh_gtfs.py --source official.zip --output staging/data --audit
```

自動処理はクリーンなmainとリモートのfast-forwardのみを許可する。dirty・未共有コミット・分岐・push競合は保護して停止し、強制push/resetや開発コピーの自動pullはしない。リモートに共有できた後だけ成功日と週次基準を進める。共有成功とPages配信成功は異なるため、Actionsと実サイトのrevisionを別途確認する。

## 障害と切り戻し

取得・変換・検証失敗では公開を変更しない。GitHub検証/公開失敗では前回正常サイトが残る。端末のstatus/logで原因を確認し、未共有変更を破棄しない。予算・認証・元観測の問題を同じ原因と混同しない。

停止は端末の `enabled` を退避する。コードは退避したスケジュールラッパーへ戻せる。公開済みデータの切り戻しは、直前コミットの索引/確認結果を取り出して通常の修正コミットとしてmainへ共有し、Pages公開後にrevisionを確認する（force/resetは使わない）。直近8世代の系統ファイルを保持するため前回索引の参照先は残る。さらに古い版は必要なファイルもGitから復元する。Git履歴の容量は別途監視する。

アプリの「このアプリについて」にGTFS確認時刻・停留所監査時刻・更新ボタンを表示する。5分ごと/画面復帰時に新版を通知し、画面内の途中データを自動で混ぜず利用者が再読込する。36時間以上確認が古い場合は警告する。古いデータのオフライン利用は更新成功扱いにしない。

保存済み地図URLは、索引を取得できた場合に同じroute_idの現行ファイルへ切り替えてから経路を作る。異なる系統IDは拒否し、URLも現行版へ更新する。索引の取得失敗は更新未確認と表示する。
